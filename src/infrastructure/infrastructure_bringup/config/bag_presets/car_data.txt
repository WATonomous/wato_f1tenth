# Car recording preset for REALSENSE_MODE=data (perception dataset): ./watod bag record
# (the default preset in data mode with alignment on) or ./watod bag record --preset car_data
#
# The car preset with depth aligned to color instead of raw depth: color as JPEG (compressed),
# aligned depth lossless (zstd), both ~30 Hz as synced pairs, plus the depth-to-color extrinsics.
# Raw depth is left out, which saves the CPU of compressing it.
#
# Left out on purpose: /pf/viz/* (costs the particle filter its 40 Hz floor), raw images
# (~1 MB per frame through DDS), raw depth, and the RealSense metadata topics.
